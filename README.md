# Kompiuterastai

## Project Description

This project is a **school project for a vocational education module** developed by the team **Kompiuterastai**.

The main goal of the project is not only to create a working website, but also to gain practical experience working as a team. During the project, we aim to learn how to:

- Work effectively as a team
- Communicate and share ideas
- Divide tasks and responsibilities
- Solve problems together
- Use version control and collaborative development tools
- Improve our HTML, CSS, and JavaScript skills

## Technologies

The project is developed using:

- **HTML** – for the structure and content of the website
- **CSS** – for styling and layout
- **JavaScript** – for functionality and interactivity
- **Git** – for version control
- **GitHub** – for collaborative development and storing the project

## Git & GitHub Workflow

We use **Git and GitHub** to work on the project together.

General rules:

- Create a separate **branch** when working on a new feature or task.
- Make regular, meaningful **commits**.
- Write clear commit messages describing what was changed.
- **Push** your branch to GitHub regularly so your work is backed up.
- Pull the latest changes before starting new work when appropriate.
- Avoid making changes directly to the main branch unless agreed by the team.
- Use **Pull Requests** to propose changes.
- Review changes before merging them into the main branch.
- Resolve merge conflicts carefully and communicate with the team when necessary.
- Keep the main branch in a working state whenever possible.

> These rules are general guidelines and may be changed as the project develops.
